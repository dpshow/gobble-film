# Gobble, gobble, hip hooray! — the film

The Dog & Pony Show's Thanksgiving film, as a one-page sing-along: the song,
with the lyric scrolling underneath and the words lighting up as they are sung.

**Live at https://film.dpshow.com/**

Plain static HTML, CSS, JavaScript and media — no build step, no framework,
no third-party scripts, no cookies, no analytics. The CSS and JavaScript are
inline in `index.html` on purpose, so the page is a single request.

Served by GitHub Pages from the root of this repository.
